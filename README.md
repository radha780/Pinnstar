# 🛠️ Fix the Broken Website — PinVerse

Welcome to **Fix the Broken Website**, a two-round debugging showdown.
Your site is broken. Your job: hunt it down, fix it, ship it.

## Event Flow

**Round 1 — The Bug Hunt**
*Tagline: Trace the glitch. Expose the bug.*

- Each team gets a broken website template (First-years and Second-years get separate tracks).
- Identify the errors, issues, and areas that need fixing.
- Document each bug: where it is, what triggers it, what *should* happen.
- Fastest + most accurate teams qualify for Round 2.

**Round 2 — The Hotfix**
*Tagline: Kill the glitch. Save the site.*

- Shortlisted teams fix the broken website and make it fully functional.
- Winners decided on correctness, completeness, and speed.
- Both rounds happen the **same day** — come prepared.
